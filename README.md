## FAQ (short version)

- **Is n8n free?** Yes when self-hosted — unlimited workflows and executions on your own ₹400–₹700/month VPS. n8n Cloud starts around €20/month.
- **n8n vs Zapier?** n8n wins on cost and complex logic (self-host = no per-task billing); Zapier wins on zero-setup convenience. Above ~1,000 task-runs/month, n8n is dramatically cheaper.
- **How long to learn n8n?** First working automation in under an hour; productive in 1–2 weeks; ready for paid client work in 3–4 weeks.
- **How much do n8n freelancers earn in India?** ₹10,000–₹40,000 per build, ₹8,000–₹35,000 per month per retainer client; 3–6 retainers ≈ ₹40k–₹1.5L/month recurring.
